# Meiji Railways Finder (1872-1912)



## 1. アプリの名前と概要

- 名前：Meiji Railways Finder (1872-1912)
- 概要：国土交通省の国土数値情報を使って、明治期（1872-1912年）日本の鉄道網の変遷を可視化するアプリ。年のスライダーを使って選んだ年までに開業した路線区間と駅だけを地図に表示でき、当該期の変化を動画として再生することもできる。明治期にどの駅や区間が開業されたか大まかに確認したい人向け。




## 2. 使い方

1. https://github.com/iyoko-someya/meiji-railways-viewer.gitにアクセスする

2. Webページの右上にある「取得方法」をクリックし、ハイパーリンクから最新の鉄道時系列データをダウンロードする

3. 「ファイルを選択」をクリックし、取得方法の手順2に従ってgeojsonファイルをインポートする

4. 駅名/路線名を検索、または左上のスライダーを使って、自分の見たい鉄道路線を確認する




## 3. 使ったデータ

- 国土数値情報「鉄道時系列データ」N05-22  
　　- 出典：国土交通省 国土数値情報ダウンロードサイト <https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N05-v2_0.html> 
　　– ライセンス：使用許諾条件は「非商用」(データの再配布不可)
　　　国土数値情報利用規約（<https://nlftp.mlit.go.jp/ksj/other/agreement.html>）
　　- 原典資料：国土政策局「国土数値情報（鉄道）」、国土交通省鉄道局監修「鉄道要覧」、国土地理院「数値地図25000」、JTBパブリッシング「停車場変遷大辞典」、各鉄道事業者の公式ウェブサイトなど

- 地理院タイル（淡色地図・白地図） 
   - 出典：国土地理院 <https://maps.gsi.go.jp/development/ichiran.html> 
　　　地理院タイルの利用規約に従い、出典を表示する
　　　地図の表示：Leaflet 1.9.4 <https://leafletjs.com/> (CDN から読み込む）



## 4. Claude Code の使い方

- 「1872年から1912年までの鉄道ネットワークを可視化するサイトを作りたい。また、各年の変遷を動画として再生できるようにしたい」と伝え、計画を立ててもらった

- 自分で判断・修正したところ
　　- 白地図と淡色地図の両方を表示するようにした
　　- 駅名・路線名の検索欄追加、表示の調整（駅名は太字、各欄を罫線で区切るなど）
　　　　- 検索結果をクリックすると、当該駅をポップアップで表示し、開業年・路線が確認できる
　　　　- 路線で検索した際には当該路線が太くなる（例えば信越線と検索すれば、データ上で信越線の駅に分類されたものが同じ路線として太く表示される）
　　　　- 検索で見つからないときは、何も表示しない
　　- 駅名の表記：名前を変更したことのある駅は、変更前の駅名も併記するようにした
　　- 国鉄とそれ以外の色分け
　　- 拡大率に合わせて、線の太さと駅の点の大きさを調整させた（縮小している時に全て表示すると密集してよく見えなくなるため）
　　- 英語ページを追加した（駅名が漢字のままになっているのは要改善）
　　- サイトの見た目の調整：UIの文字を少し大きめにし、出典を折りたたみ可能にした
　　- 元データが再配布不可のため、ユーザー自らがデータをダウンロードして表示させるビューアに変更




## 5. 既知の制限（注意書きも含む）

- 英語版サイトでは駅名がローマ字ではなく漢字表記になっている（作業時間とクレジットが足りない恐れがあるため）。地図も英語版のものを導入できていない

- 1950年より前に廃止された路線・駅がデータに含まれていない（元データが「昭和25年（1950年）以降の整備状況」のため、表示されるのは、「当時開業していて、1950年以降も残った路線・駅」のみとなる）。

- 駅の開業年は、**現在の駅の位置での開業年**なので、初代の駅ではない場合がある。
  　- 例：1872年に開業した初代の新橋駅（のちの汐留駅）は、データに含まれない。JR の「新橋」は、現在の位置に1909年に開業した烏森駅（1914年に新橋駅に改称）にあたるため、開業年＝1909年と表示される。
  　- 新橋駅の近くには、東京都の路面電車の停留所「新橋」（1903年開業）もあり、鉄道の駅と近くで重なって見える。
  　- このため、1872年の新橋―横浜間の開通は、1872年の駅として品川・川崎・鶴見・桜木町だけが表示される（新橋・初代横浜は表示されない）。

- 「区間」の数は、運営会社と路線名が全く同じ区間を1つとして数えている（例えば、東海道線は、運営会社が違う分だけ複数になっている）

- 開業年が不明（999）の路線・駅は、地図に表示されない。

- 位置は現在の鉄道線路に基づくため、当時の実際の線路とは多少異なる場合がある。また、アプリを軽量化するうえで座標を簡略化しているため、約10mの誤差が生じる。

- 同じ位置にある駅は1つにまとめている。名前が全く違う駅（例：筑紫／秩父別）も、同じ位置ならまとめて「筑紫（秩父別）」のように表示される。これは、名前の変化が駅の移動よりも改名のみを意味するためである。

- 駅の詳細は、地図をある程度拡大しないと表示されない（拡大率6以上で表示）。縮小しているときは、選択期間内の駅の件数だけを画面上部に表示する。
　　- 駅名は、「黒沢尻（北上）」のように新旧の名前を併記している駅でも、拡大をしなければ改名後の名前（現在に最も近いもの）だけが表示される。

- 駅が密集した場所（1913年の都市部など）では、駅名が重なって読みにくくなる。

- 「旧国鉄」は、データに記された事業者種別がJR在来線（JR各社と日本国有鉄道）のものである。

- 使いづらさ：
　　- 背景の白地図は、拡大率14より大きく拡大すると引き伸ばされ、変な余白ができる
　　- 路線を選択すると開業年が表示されるが、路線全体が貫通した年ではなく、ポップアップした駅の開業年が表示されるので、静止時に他の区間の開業年を確認する場合には駅を一つずつクリックしなければならない




## 6. 機能一覧

- 年のスライダー（1872-1912年）で、選んだ年までに開業した路線と駅を表示
   - 再生ボタンで、年を自動で進めて変化を見られる

- 「選択された路線/駅」の件数を表示（路線は運営会社＋路線名で数える）

- 路線を、旧国鉄（青 `#266EBD`）とそれ以外（オレンジ `#E67E22`）で色分けして表示

- いま選んでいる年に開業した新設区間の線を、ほかの線の2倍の太さで表示

- 駅名・路線名の検索欄。選ぶと地図が動いてポップアップが開く
  - 候補は、「種別（網掛け）｜名前（太字）｜開業年｜路線名（路線の場合は運営会社）」の4つのセルで表示

- 地図上の駅・路線をクリックしてもポップアップを表示

- 背景地図（淡色地図／白地図）を、右上のボタンで切り替え
