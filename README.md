# Meiji Railways Finder (1872-1912)

## 1. アプリの名前と概要

- 名前：Meiji Railways Finder (1872-1912)
- 概要：国土交通省の国土数値情報を使って、明治期（1872-1912年）日本の鉄道網の変遷を可視化するアプリ。
  - 年のスライダーで、選んだ年までに開業した路線と駅だけを地図に表示します。


## 2. 使い方

1. ターミナルでこのフォルダに移動します。
2. サーバーを起動します。
   - Mac / Linux：`python3 server.py`
   - Windows：`python server.py`
3. ブラウザで <http://localhost:3000/> を開きます。
4. 止めるときは、ターミナルで `Ctrl + C` を押します。

※ `server.py` は授業用のサーバーです。書き換えません。
※ ページが開かないときは、サーバーが動いているか確認してください。

| 国土数値情報「鉄道時系列データ」N05-23 | 路線・駅のデータ | 国土交通省 国土数値情報ダウンロードサイト <https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N05-v2_0.html> | 使用許諾条件は「非商用」。国土数値情報利用規約（<https://nlftp.mlit.go.jp/ksj/other/agreement.html>）に従う。**複製物の再配布は不可** |
| 地理院タイル（淡色地図・白地図） | 背景地図 | 国土地理院 <https://maps.gsi.go.jp/development/ichiran.html> | 地理院タイルの利用規約に従い、出典を表示する |
| Leaflet 1.9.4 | 地図の表示（CDN から読み込む） | <https://leafletjs.com/> | BSD-2-Clause |

- 取得したデータの原典資料：国土政策局「国土数値情報（鉄道）」、国土交通省鉄道局監修「鉄道要覧」、国土地理院「数値地図25000」、JTBパブリッシング「停車場変遷大辞典」、各鉄道事業者の公式ウェブサイトなど。
- データは、`data/Rail-ts/`（元データ。約265MB）から、`data/make_rail_data.py` で必要な部分だけを抜き出して、`data/rail-1872-1913.json` を作っています。
  - 開業年が1913年以下の路線・駅だけを残す。
  - 開業年が「不明（999）」のものは除く。
  - 同じ位置の駅を1つにまとめる（旧名を主にして、新しい名前を（）で併記。通る路線ごとの開業年も記録）。
  - 座標を小数4桁（約10m）に丸め、点を間引いて、ファイルを軽くする。
- 元データ（`data/Rail-ts/`）は、`.gitignore` に入れてあり、Git や公開ページには含めません。
- 個人情報や、公開してよいか分からないデータは使いません。
- ページ下部と地図の右下にも、同じ出典を表示しています。

### 公開するときの注意

国土数値情報の「鉄道時系列データ」は**非商用**で、利用規約では**複製物の再配布が認められていません**。このアプリは、元データから加工した `data/rail-1872-1913.json` を使うため、GitHub Pages など、インターネットで公開する前に、授業の先生や国土数値情報の事務局に、公開してよいかを確認してください。確認できるまでは、ローカル（`localhost`）で使うだけにしてください。

## 5. 既知の制限

- **1950年より前に廃止された路線・駅は、データに含まれません。** 元データが「昭和25年（1950年）以降の整備状況」のためです。表示されるのは、「当時開業していて、1950年以降も残った路線・駅」です。
- 駅の開業年は、**現在の駅の位置での開業年**です。初代の駅ではない場合があります。
  - 例：1872年に開業した初代の新橋駅（のちの汐留駅）は、データにありません。JR の「新橋」は、現在の位置に1909年に開業した烏森駅（1914年に新橋駅に改称）にあたるため、1909年と表示されます。
  - 新橋駅の近くには、東京都の路面電車の停留所「新橋」（1903年開業）もあり、鉄道の駅と近くで重なって見えます。
  - このため、1872年の新橋―横浜間の開通は、1872年の駅として品川・川崎・鶴見・桜木町だけが表示されます（新橋・初代横浜は出ません）。
- 開業年が不明（999）の路線・駅は、地図に出ません。
- 位置は現在の線形に基づくので、当時の実際の線路とは異なる場合があります。座標を簡略化しているため、約10mの誤差があります。
- 「路線」の数は、運営会社と路線名が同じ区間を1本として数えています（東海道線は、運営会社が違う分、複数に数えます）。
- 同じ位置にある駅は1つにまとめています。名前が全く違う駅（例：筑紫／秩父別）も、同じ位置ならまとめて、`筑紫（秩父別）` のように表示します。
- 駅の点と駅名は、地図をある程度拡大しないと表示されません（拡大率6以上で表示）。縮小しているときは、駅の件数だけを画面上部に表示します。
- 駅名は、「黒沢尻（北上）」のように新旧の名前を併記している駅でも、地図上では（）の前の名前だけを表示します。全部の名前は、ポップアップで見られます。
- 駅が多い場所（1913年の都市部など）では、駅名が重なって読みにくくなることがあります。
- 「旧国鉄」は、データの事業者種別が JR在来線（JR各社と日本国有鉄道）のものです。
- 背景の白地図は、拡大率14より大きく拡大すると、画像が引き伸ばされます。
- サーバーは自分のPC（`127.0.0.1`）からだけ見られます。
- 名前が「.」で始まるファイルやフォルダ（`.claude` など）は、サーバー経由では見られません（403 エラー）。

## 6. 機能一覧

- 年のスライダー（1872〜1913年）で、選んだ年までに開業した路線と駅を表示
- 「選択された路線 / 駅」の件数を表示（路線は運営会社＋路線名で数える）
- 再生ボタンで、年を自動で進めて変化を見られる
- 路線を、旧国鉄（青 `#266EBD`）とそれ以外（オレンジ `#E67E22`）で色分けして表示（地図の左下に凡例）
- いま選んでいる年に開業した新設区間の線を、ほかの線の2倍の太さで表示
- 拡大率に合わせて、線の太さと駅の点の大きさを調整（縮小しているときは、駅の点を表示せず、拡大するほど大きく表示）
- 地図を拡大率6以上に拡大すると、駅の点の右に駅名を表示（画面に入っている駅だけに付ける）
- 駅名・路線名の検索欄。選ぶと地図が動いてポップアップが開く
  - 候補は、「種別（網掛け）｜名前（太字）｜開業年｜路線名（路線の場合は運営会社）」の4つのセルで表示
- 地図上の駅・路線をクリックしてもポップアップを表示
- 検索で見つからないときは、何も表示しない
- 背景地図（淡色地図／白地図）を、右上のボタンで切り替え
- 出典・クレジットの欄を、矢印ボタンで折りたためる
